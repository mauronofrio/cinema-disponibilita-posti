# 2Tickets Chain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the 2Tickets.it platform (small independent cinemas, mostly in Southern Italy - e.g. Cine Teatro Norba in Conversano, Cityplex Vignola in Polignano a Mare, Orfeo in Taranto) as a fifth `CinemaChain`, with programme, real sold-out flags and full seat maps, cinema titles only (no theatre).

**Architecture:** Same shape as every other chain: a `TwoTicketsApiClient` (raw HTTP, plain text), pure parsers under `lib/core/chains/two_tickets/` (run in `compute()`), and a `TwoTicketsChainApi implements ChainApi` that caches a cinema's whole programme (all dates arrive at once). Cinemas ship in the bundled `assets/cinemas.json`, generated by a new `tools/scrape_twotickets_cinemas.py` that geocodes addresses once (2Tickets publishes no coordinates and no venue list).

**Tech Stack:** Flutter/Dart, Riverpod 3, Dio 5, `flutter_test`; Python 3 stdlib for the catalog script.

**Spec:** No separate spec document - the verified facts and decisions are in the **Context** section below (all confirmed live on 13 Oct 2026, by direct HTTP probing and by an independent browser-based analysis).

## Context (verified facts the tasks rely on)

- Base: `https://www.2tickets.it/biglietto`. ASP.NET MVC, server-rendered HTML. No robots.txt, no sitemap, **no venue index endpoint, no coordinates anywhere**.
- **Venue page** `GET /esercizio/titoli/{idLocale}`: `<div class="cinema-header"><h1>{name}</h1><p>…{street}, {number}  {CITY} ({PROV})</p>`, then one `<div class="titolo-card">` per title. Each card links `/biglietto/Acquisto/Checkout/{idFilm}/{idLocale}?settore=C` for **cinema** and `?settore=T` for **theatre**, and shows a tag `<i class="bi bi-tag-fill"></i> CINEMA` (or `TEATRO PROSA`), `<h3 class="titolo-title">`, `NNN min`, poster `<img src>` (a `locandina_null_*.jpg` placeholder means "no poster"). Titles arrive with doubled apostrophes (`L&#x27;&#x27;ESTRANEA` → `L''ESTRANEA`) and sometimes a trailing space.
- **Checkout page** `GET /Acquisto/Checkout/{idFilm}/{idLocale}?settore=C` (~650 KB, ~210 KB gzipped): JS config with `serverEse: "pf2.twoitalia.it"`, `portEse: "80"`, and one `orariServer.push({ idEvento: 610899, idEventoEse: 610899, data: '2026-10-13', ora: '17.30', sala: "N1", postiLiberi: 373, is3D: false, isVO: false, isAtmos: false, titolo: "" });` per performance. **Every on-sale date is already in the page** (changing date in the site's calendar makes no request).
- `postiLiberi`: `0` = sold out, `1..5` = "ultimi posti", `9999` = seats not tracked (treat as available).
- **Sectors** `GET /api/sala/settori?idEvento={id}&tipo=C&orarioTurno=HH:MM&serverEse={ese}&portEse={port}` → JSON `{esito:"OK", settori:[{idSettore, descrizione, modVend:"2"|"1", hasNumerazione, totPostiLiberi, capienza, righe, colonne, sala, ...}], nomeEsercizio, cittaEsercizio, ...}`. `modVend "1"` / `hasNumerazione:false` = unnumbered ("Posto Unico", no map). In multi-sector rooms `capienza` is the **whole room's** capacity repeated on every sector.
- **Seats** `GET /api/sala/posti?idSettore={id}&modVend=2&idEvento={id}&orarioTurno=HH.MM&token=&clienteId=0&serverEse={ese}&portEse={port}&titoloEvento=&dataOraEvento=` → `{esito, righeSettore, colonneSettore, tuttiIPosti:[...]}`, a full row-major grid (`index = row * colonne + col`), gaps included. Rule copied from the site's own JS: gap if `fila == '-' || stato == 0 || isBuco`; free if `stato == 2 || isLibero`; otherwise taken. **Sold seat verified:** `stato: 201, isVenduto: true`. Row 0 is the row nearest the screen (screen at top, like our grid). A row can carry two `fila` spellings for its two blocks (`AA13…AA1 · A1…A13`) - same row.
- Reading `settori`/`posti` is a plain GET: it **blocks nothing**. Seats are only held by `POST /api/sala/addposto` (clicking a seat) - the app must never call it, nor any other POST.
- ⚠️ `settori`, `tariffe` and the checkout page config expose `tipoBanca`/`userBanca`/`pwdBanca` (the cinema's payment gateway credentials - their bug). **Never parse, store, log or commit them.** The committed fixtures already have them removed/`REDACTED`.
- reCAPTCHA exists only in the purchase flow - ignored (user decision).

## Global Constraints

- Commit messages in **Italian**; **never** add a `Co-Authored-By` trailer.
- Do not push; do not build APKs onto the Desktop.
- Cinema titles only: a title counts only if its link has `settore=C` **and** its tag reads `CINEMA`. Never filter venues by name ("Cine Teatro Norba", "Cinema Teatro Orfeo" are real cinemas).
- No POST requests to 2Tickets, ever. Only the four GETs above.
- Be polite to a small site: at most **3** concurrent requests per programme/seat-map load; the catalog script waits **1 s** between requests.
- Bank fields (`userBanca`, `pwdBanca`, `tipoBanca`) must never appear in models, logs or committed files.
- Existing code idioms: `runChainParsing(...)` around every `ChainApi` method, `compute()` for heavy parsing, `TtlCache` + in-flight dedup for programme caching, `Clock` injected (never `DateTime.now()` in chain code).
- Run `flutter analyze` (must print `No issues found!`) and the full `flutter test` before every commit.

## Review Focus

1. **A venue with no cinema titles right now** (theatre-only week, or nothing on sale) → home shows the normal "no showings" state, not an error. Pinned in Task 5.
2. **`postiLiberi: 9999` (untracked)** → session shown as normally bookable, never as sold out. Pinned in Task 3.
3. **Multi-sector room** (Orfeo Taranto: 7 sectors) → every numbered sector rendered, separated by a blank row, each as its own legend category; a **mix** of numbered and unnumbered sectors keeps both. Pinned in Tasks 4 and 5.
4. **Unnumbered capacity in a multi-sector room** (`capienza` is room-wide there) → show only "N liberi", never a wrong "N liberi su 773", and keep it out of the totals. Pinned in Task 4.
5. **Bank credentials sneaking into the repo** when someone refreshes a fixture later → a hygiene test fails. Pinned in Task 1.

import '../parsing_utils.dart';

/// One cinema title listed on a 2Tickets venue page - metadata only, the
/// showtimes live on the film's own checkout page (see
/// two_tickets_checkout_parser.dart).
class TwoTicketsVenueFilm {
  const TwoTicketsVenueFilm({
    required this.filmId,
    required this.title,
    required this.posterUrl,
    required this.runningTime,
  });

  final String filmId;
  final String title;
  final String? posterUrl;
  final int? runningTime;
}

class TwoTicketsVenuePage {
  const TwoTicketsVenuePage({
    required this.name,
    required this.address,
    required this.films,
  });

  final String name;
  final String address;
  final List<TwoTicketsVenueFilm> films;
}

final _header = RegExp(
  r'<div class="cinema-header">\s*<h1>(.*?)</h1>\s*<p>(.*?)</p>',
  dotAll: true,
);
final _card = RegExp(
  r'<div class="titolo-card"(.*?)<div class="btn-fasticket-container">',
  dotAll: true,
);
final _checkoutLink = RegExp(r'Acquisto/Checkout/(\d+)/\d+\?settore=(\w)');
final _tag = RegExp(r'bi-tag-fill"></i>\s*([^<]+)<');
final _title = RegExp(r'<h3 class="titolo-title">(.*?)</h3>', dotAll: true);
final _poster = RegExp(r'<img src="([^"]+)"');
final _minutes = RegExp(r'(\d+)\s*min\b');
final _tags = RegExp(r'<[^>]*>');
final _spaces = RegExp(r'\s+');

/// 2Tickets titles come out of the venue's own database with SQL-style
/// doubled apostrophes ("L''ESTRANEA") and, now and then, trailing spaces.
String cleanTwoTicketsTitle(String raw) => decodeHtmlEntities(raw)
    .replaceAll("''", "'")
    .replaceAll(_spaces, ' ')
    .trim();

/// Parses `/biglietto/esercizio/titoli/{idLocale}`.
///
/// The same venue often sells theatre too (Cine Teatro Norba lists 8 plays
/// alongside 6 films) - a title is kept only when its link carries
/// `settore=C` **and** its tag says CINEMA. Filtering by venue name would
/// be wrong: many real cinemas are called "Cinema Teatro ...".
TwoTicketsVenuePage parseTwoTicketsVenuePage(String html) {
  final header = _header.firstMatch(html);
  final name = header == null ? '' : cleanTwoTicketsTitle(header.group(1)!);
  final address = header == null
      ? ''
      : decodeHtmlEntities(header.group(2)!.replaceAll(_tags, ' '))
          .replaceAll(_spaces, ' ')
          .trim();

  final films = <TwoTicketsVenueFilm>[];
  for (final card in _card.allMatches(html)) {
    final body = card.group(1)!;
    final link = _checkoutLink.firstMatch(body);
    if (link == null || link.group(2) != 'C') continue;
    final tag = _tag.firstMatch(body)?.group(1)?.trim().toUpperCase() ?? '';
    if (!tag.contains('CINEMA')) continue;
    final title = _title.firstMatch(body);
    if (title == null) continue;
    final poster = _poster.firstMatch(body)?.group(1);
    films.add(
      TwoTicketsVenueFilm(
        filmId: link.group(1)!,
        title: cleanTwoTicketsTitle(title.group(1)!),
        posterUrl: poster == null || poster.contains('locandina_null')
            ? null
            : poster,
        runningTime: int.tryParse(_minutes.firstMatch(body)?.group(1) ?? ''),
      ),
    );
  }
  return TwoTicketsVenuePage(name: name, address: address, films: films);
}
```

/// One showtime from a 2Tickets checkout page's embedded `orariServer` list.
class TwoTicketsPerformance {
  const TwoTicketsPerformance({
    required this.eventId,
    required this.startTime,
    required this.rawTime,
    required this.hall,
    required this.freeSeats,
    required this.is3D,
    required this.isOriginalLanguage,
    required this.isAtmos,
  });

  final String eventId;
  final DateTime startTime;

  /// The time exactly as sent ("21.30") - the booking link and the seats
  /// call both want it in this form.
  final String rawTime;
  final String hall;

  /// `postiLiberi`. 9999 is the site's own "not tracked" sentinel (its JS
  /// treats it as plenty available), so only 0 means sold out.
  final int freeSeats;
  final bool is3D;
  final bool isOriginalLanguage;
  final bool isAtmos;

  bool get isSoldOut => freeSeats == 0;
}

class TwoTicketsCheckoutPage {
  const TwoTicketsCheckoutPage({
    required this.serverEse,
    required this.portEse,
    required this.performances,
  });

  final String serverEse;
  final String portEse;
  final List<TwoTicketsPerformance> performances;
}

/// Parses `/biglietto/Acquisto/Checkout/{idFilm}/{idLocale}?settore=C`.
///
/// The page embeds **every** on-sale date for this film at this venue (the
/// site's calendar is built client-side from it - confirmed: switching date
/// makes no request), so one page per film is the whole schedule. Only the
/// handful of fields below are read; in particular the page config's
/// payment-gateway credentials (exposed by the site, not ours to touch) are
/// never looked at.
TwoTicketsCheckoutPage parseTwoTicketsCheckoutPage(String html) {
  final performances = <TwoTicketsPerformance>[];
  for (final match in _push.allMatches(html)) {

    final id = _field(block, 'idEvento');
    final date = _field(block, 'data');
    final time = _field(block, 'ora');
    if (id == null || date == null || time == null) continue;
    final day = DateTime.tryParse(date);
    final hm = time.split('.');
    final hour = int.tryParse(hm.first);
    final minute = hm.length > 1 ? int.tryParse(hm[1]) : 0;
    if (day == null || hour == null || minute == null) continue;
    performances.add(
      TwoTicketsPerformance(
        eventId: id,
        startTime: DateTime(day.year, day.month, day.day, hour, minute),
        rawTime: time,
        hall: _field(block, 'sala') ?? '',
        freeSeats: int.tryParse(_field(block, 'postiLiberi') ?? '') ?? 9999,
        is3D: _field(block, 'is3D') == 'true',
        isOriginalLanguage: _field(block, 'isVO') == 'true',
        isAtmos: _field(block, 'isAtmos') == 'true',
      ),
    );
  }
  return TwoTicketsCheckoutPage(
    serverEse: _serverEse.firstMatch(html)?.group(1) ?? '',
    portEse: _portEse.firstMatch(html)?.group(1) ?? '',

class TwoTicketsSector {

    required this.hall,

    required this.freeSeats,
    required this.capacity,
  });

  final String name;
  final String hall;
  final bool isNumbered;
  final int freeSeats;

  /// `capienza` - careful: in a multi-sector room this is the whole room's
  /// capacity, repeated on every sector (Orfeo Taranto: 773 on all 7).
  final int capacity;

/// Parses `/api/sala/settori`. Only the fields below are read - the
/// response also carries the cinema's payment-gateway credentials (the
/// site's bug), which are deliberately never touched.
List<TwoTicketsSector> parseTwoTicketsSectors(String body) {
  final json = jsonDecode(body) as Map<String, dynamic>;
  if (json['esito'] != 'OK') return const [];
  return [
    for (final raw in (json['settori'] as List<dynamic>? ?? const []))
      if (raw is Map<String, dynamic> && raw['idSettore'] is num)
        TwoTicketsSector(
          id: (raw['idSettore'] as num).toInt(),
          name: (raw['descrizione'] as String?)?.trim() ?? '',
          hall: (raw['sala'] as String?)?.trim() ?? '',
          isNumbered:
              raw['hasNumerazione'] == true && '${raw['modVend']}' != '1',
          freeSeats: (raw['totPostiLiberi'] as num?)?.toInt() ?? 0,
          capacity: (raw['capienza'] as num?)?.toInt() ?? 0,
        ),
  ];
}

class TwoTicketsSeatMapPayload {
  const TwoTicketsSeatMapPayload({
    required this.sectors,
    required this.seatsJsonBySectorId,
  });

  final List<TwoTicketsSector> sectors;

  /// Raw `/api/sala/posti` bodies, numbered sectors only.
  final Map<int, String> seatsJsonBySectorId;
}

/// Same classification as the site's own map renderer (checkout JS,
/// `renderMappa`): a gap if `fila == '-'`, `stato == 0` or `isBuco`; free
/// if `stato == 2` or `isLibero`; anything else is taken (sold seats are
/// `stato 201` / `isVenduto`, verified live). Unknown future states
/// therefore read as taken - the safe direction for "can I get a seat".
Seat? _seat(Map<String, dynamic> p, int row, int col, String sectorCode) {
  final fila = '${p['fila'] ?? '-'}';
  final stato = (p['stato'] as num?)?.toInt() ?? 0;
  if (fila == '-' || stato == 0 || p['isBuco'] == true) return null;
  final accessible =
      p['isHandicap'] == true || ((p['handicap'] as num?) ?? 0) != 0;
  final notForSale = ((p['nonVendibile'] as num?) ?? 0) != 0;
  final free = stato == 2 || p['isLibero'] == true;
  final status = notForSale
      ? SeatStatus.special
      : free
      ? (accessible ? SeatStatus.accessibility : SeatStatus.available)
      : SeatStatus.occupied;
  return Seat(
    rowIndex: row,
    columnIndex: col,
    name: (p['codicePosto'] as String?) ?? '$fila${p['colonna'] ?? ''}',
    status: status,
    areaCategoryCode: sectorCode,
    isAccessibility: accessible,
  );
}

/// A row's two blocks can be spelled differently (`AA13…AA1 · A1…A13` -
/// verified on Moderno Anzio): they are one row, so the shortest spelling
/// is the label, while each seat keeps its full code as its name.
String _rowLabel(Iterable<Map<String, dynamic>> cells) {
  String? best;
  for (final p in cells) {
    final fila = '${p['fila'] ?? '-'}';
    if (fila == '-' || p['isBuco'] == true) continue;
    if (best == null || fila.length < best.length) best = fila;
  }
  return best ?? '';
}

SeatMap buildTwoTicketsSeatMap(TwoTicketsSeatMapPayload payload) {
  final numbered = payload.sectors.where((s) => s.isNumbered).toList();
  final unnumbered = payload.sectors.where((s) => !s.isNumbered).toList();
  final rows = <SeatRow>[];
  final categories = <AreaCategory>[];
  var totalColumns = 0;

  for (final sector in numbered) {
    final body = payload.seatsJsonBySectorId[sector.id];
    if (body == null) continue;
    final json = jsonDecode(body) as Map<String, dynamic>;
    if (json['esito'] != 'OK') continue;
    final cols = (json['colonneSettore'] as num?)?.toInt() ?? 0;
    final rowCount = (json['righeSettore'] as num?)?.toInt() ?? 0;
    final cells = (json['tuttiIPosti'] as List<dynamic>? ?? const [])
        .whereType<Map<String, dynamic>>()
        .toList();
    if (cols == 0 || rowCount == 0) continue;
    if (cols > totalColumns) totalColumns = cols;
    final code = '${sector.id}';
    if (rows.isNotEmpty) {
      // One blank row between sectors, so stacked sectors (stalls, then
      // galleries, then boxes) read as separate blocks.
      rows.add(SeatRow(rowLabel: '', rowIndex: rows.length, seats: const []));
    }
    for (var r = 0; r < rowCount; r++) {
      final start = r * cols;
      if (start >= cells.length) break;
      final rowCells = cells.sublist(start, (start + cols).clamp(0, cells.length));
      rows.add(
        SeatRow(
          rowLabel: _rowLabel(rowCells),
          rowIndex: rows.length,
          seats: [
            for (var c = 0; c < rowCells.length; c++)
              _seat(rowCells[c], r, c, code),
          ],
        ),
      );
    }
    categories.add(
      AreaCategory(
        code: code,
        name: sector.name,
        color: null,
        isSoldOut: sector.freeSeats == 0,
      ),
    );
  }

  final singleSector = payload.sectors.length == 1;
  return SeatMap(
    screenLabel: payload.sectors.isEmpty ? '' : payload.sectors.first.hall,
    totalRows: rows.length,
    totalColumns: totalColumns,
    rows: rows,
    areaCategories: categories,
    unnumberedSectors: [
      for (final s in unnumbered)
        UnnumberedSector(
          name: s.name,
          freeSeats: s.freeSeats,
          capacity: singleSector ? s.capacity : null,
        ),
    ],
  );
}

    'serverEse': serverEse,

    required String rawTime,

/// [ChainApi] for 2Tickets.it venues.
///
/// A venue's programme costs one venue page plus one checkout page per
/// cinema title (each ~210 KB gzipped) - but each checkout page already
/// holds every on-sale date, so the whole programme is fetched once, cached
/// for [_programmeTtl], and every day/date query is served from it. At most
/// [_maxConcurrent] pages are requested at a time: a small site.
class TwoTicketsChainApi implements ChainApi {
  TwoTicketsChainApi(this._client, Clock clock)
    : _programmes = TtlCache(clock, _programmeTtl);

  static const _programmeTtl = Duration(minutes: 10);
  static const _maxConcurrent = 3;

  final TwoTicketsApiClient _client;
  final TtlCache<String, List<Film>> _programmes;
  final _inFlight = <String, Future<List<Film>>>{};

  Future<List<Film>> _programme(Cinema cinema) {
    final cached = _programmes.get(cinema.cinemaId);
    if (cached != null) return Future.value(cached);
    final pending = _inFlight[cinema.cinemaId];
    if (pending != null) return pending;
    final future = _fetchProgramme(cinema).then((films) {
      _programmes.set(cinema.cinemaId, films);
      return films;
    });
    _inFlight[cinema.cinemaId] = future;
    future.whenComplete(() => _inFlight.remove(cinema.cinemaId)).ignore();
    return future;
  }

  /// Runs [task] over [items] with at most [_maxConcurrent] in flight,
  /// preserving input order in the result.
  static Future<List<R>> _pooled<T, R>(
    List<T> items,
    Future<R> Function(T) task,
  ) async {
    final results = <R>[];
    for (var i = 0; i < items.length; i += _maxConcurrent) {
      final batch = items.skip(i).take(_maxConcurrent);
      results.addAll(await Future.wait(batch.map(task)));
    }
    return results;
  }

  Future<List<Film>> _fetchProgramme(Cinema cinema) async {
    final venue = await compute(
      parseTwoTicketsVenuePage,
      await _client.getVenuePage(cinema.cinemaId),
    );
    final pages = await _pooled(venue.films, (TwoTicketsVenueFilm film) async {
      final html = await _client.getCheckoutPage(film.filmId, cinema.cinemaId);
      return compute(parseTwoTicketsCheckoutPage, html);
    });

    final films = <Film>[];
    for (var i = 0; i < venue.films.length; i++) {
      final film = venue.films[i];
      final page = pages[i];
      final byDay = <DateTime, List<Session>>{};
      for (final p in page.performances) {
        final day = DateTime(p.startTime.year, p.startTime.month, p.startTime.day);
        byDay.putIfAbsent(day, () => []).add(_session(cinema, film, page, p));
      }
      if (byDay.isEmpty) continue;
      final days = byDay.keys.toList()..sort();
      films.add(
        Film(
          filmId: film.filmId,
          title: film.title,
          posterImageSrc: film.posterUrl,
          runningTime: film.runningTime,
          showingGroups: [
            for (final d in days)
              ShowingGroup(
                date: d,
                sessions: byDay[d]!
                  ..sort((a, b) => a.startTime.compareTo(b.startTime)),
              ),
          ],
        ),
      );
    }
    films.sort((a, b) => a.title.compareTo(b.title));
    return films;
  }

  Session _session(
    Cinema cinema,
    TwoTicketsVenueFilm film,
    TwoTicketsCheckoutPage page,
    TwoTicketsPerformance p,
  ) {
    return Session(
      sessionId: p.eventId,
      startTime: p.startTime,
      endTime: p.startTime.add(Duration(minutes: film.runningTime ?? 120)),
      screenName: p.hall,
      isSoldOut: p.isSoldOut,
      formattedPrice: null,
      isPriceVisible: false,
      attributes: [
        if (p.is3D)
          const SessionAttribute(name: '3D', attributeType: 'screen', color: null),
        if (p.isAtmos)
          const SessionAttribute(name: 'ATMOS', attributeType: 'screen', color: null),
        // Tagged on every session (like UCI): "ITA" is a default language
        // and stays silent, "VO" gets a caption - see isNotableLanguage.
        SessionAttribute(
          name: p.isOriginalLanguage ? 'VO' : 'ITA',
          attributeType: 'Language',
          color: null,
        ),
      ],
      bookingPath:
          '$twoTicketsBaseUrl/Acquisto/Checkout/${film.filmId}/'
          '${cinema.cinemaId}/${p.eventId}?settore=C&orario=${p.rawTime}',
      twoTicketsServerEse: page.serverEse,
      twoTicketsPortEse: page.portEse,
    );
  }

  @override
  Future<List<ShowingDate>> getShowingDates(Cinema cinema) {
    return runChainParsing(() async {
      final films = await _programme(cinema);
      final days = {
        for (final f in films)
          for (final g in f.showingGroups)
            if (g.sessions.isNotEmpty) g.date,
      }.toList()..sort();
      return [for (final d in days) ShowingDate(date: d, hasShowings: true)];
    });
  }

  @override
  Future<List<Film>> getFilmsForDay(Cinema cinema, DateTime day) {
    // [day] unused: every date arrives together (see class doc).
    return runChainParsing(() => _programme(cinema));
  }

  @override
  Future<SeatMap> getSeatMap(Cinema cinema, Session session) {
    return runChainParsing(() async {
      final ese = session.twoTicketsServerEse;
      final port = session.twoTicketsPortEse;
      if (ese == null || port == null) {
        throw ApiException(AppLocalizations.current.seatsLoadError);
      }
      final t = session.startTime;
      final hh = t.hour.toString().padLeft(2, '0');
      final mm = t.minute.toString().padLeft(2, '0');
      final sectors = parseTwoTicketsSectors(
        await _client.getSectors(
          eventId: session.sessionId,
          time: '$hh:$mm',
          serverEse: ese,
          portEse: port,
        ),
      );
      final numbered = sectors.where((s) => s.isNumbered).toList();
      final bodies = await _pooled(
        numbered,
        (TwoTicketsSector s) => _client.getSeats(
          sectorId: s.id,
          eventId: session.sessionId,
          rawTime: '$hh.$mm',
          serverEse: ese,
          portEse: port,
        ),
      );
      return compute(
        buildTwoTicketsSeatMap,
        TwoTicketsSeatMapPayload(
          sectors: sectors,
          seatsJsonBySectorId: {
            for (var i = 0; i < numbered.length; i++) numbered[i].id: bodies[i],
          },
        ),
      );
    });
  }
}

final twoTicketsChainApiProvider = Provider<TwoTicketsChainApi>((ref) {
  return TwoTicketsChainApi(
    ref.watch(twoTicketsApiClientProvider),
    ref.watch(clockProvider),
  );
});

"""Builds the 2Tickets.it part of assets/cinemas.json.

2Tickets publishes no venue list and no coordinates (confirmed 13 Oct 2026),
so venues are discovered from the films currently on sale - every film's
detail page lists each venue showing it - and geocoded once via
OpenStreetMap Nominatim. Results are MERGED into the existing catalog,
never replacing it: a venue with nothing on sale today keeps its entry
from an earlier run. Pass extra venue ids by hand for venues known to
exist but not currently discoverable:

    python tools/scrape_twotickets_cinemas.py 609

A venue is included only if it has at least one CINEMA title
(link settore=C and tag "CINEMA") - pure theatres are skipped. Never
filter by name: "Cine Teatro Norba" and "Cinema Teatro Orfeo" are cinemas.

Polite by design: one request per second to 2Tickets, and Nominatim's own
1 req/s policy. Reads nothing but public GET pages.
"""

import html
import json
import re
import sys
import time
import urllib.parse
import urllib.request

BASE = "https://www.2tickets.it/biglietto"
CATALOG = "assets/cinemas.json"
UA_SITE = ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
           "(KHTML, like Gecko) Chrome/126.0 Safari/537.36")
UA_GEO = ("CinemaDisponibilitaPosti-catalog/1.0 "
          "(github.com/mauronofrio/cinema-disponibilita-posti)")


def get(url, ua=UA_SITE):
    req = urllib.request.Request(url, headers={"User-Agent": ua})
    with urllib.request.urlopen(req, timeout=30) as r:
        body = r.read().decode("utf-8", errors="replace")
    time.sleep(1.0)
    return body


def film_ids():
    ids = set()
    for page in ("", "/cinema"):
        ids |= set(re.findall(r"/biglietto/Evento/Dettaglio/(\d+)/C", get(BASE + page)))
    return sorted(ids, key=int)


def venue_ids_from_film(film_id):
    page = get(f"{BASE}/Evento/Dettaglio/{film_id}/C")
    return set(re.findall(r"/Acquisto/Checkout/\d+/(\d+)/\d+", page)) - {"0"}


def clean(s):
    s = html.unescape(re.sub(r"<[^>]*>", " ", s)).replace("''", "'")
    return re.sub(r"\s+", " ", s).strip()


def venue(venue_id):
    page = get(f"{BASE}/esercizio/titoli/{venue_id}")
    m = re.search(r'<div class="cinema-header">\s*<h1>(.*?)</h1>\s*<p>(.*?)</p>', page, re.S)
    if not m:
        return None
    has_cinema = False
    for card in re.findall(r'<div class="titolo-card"(.*?)<div class="btn-fasticket-container">', page, re.S):
        link = re.search(r"Checkout/\d+/\d+\?settore=(\w)", card)
        tag = re.search(r'bi-tag-fill"></i>\s*([^<]+)<', card)
        if link and link.group(1) == "C" and tag and "CINEMA" in tag.group(1).upper():
            has_cinema = True
            break
    return {"name": clean(m.group(1)), "address": clean(m.group(2)), "has_cinema": has_cinema}


def pretty_address(raw):
    # "Piazza della Repubblica, 29 CONVERSANO (BA)" -> "... 29 Conversano (BA)"
    m = re.match(r"^(.*?)\s+([A-ZÀ-Ù' ]{2,}?)\s*\((\w{2})\)\s*$", raw)
    if not m:
        return raw
    return f"{m.group(1)} {m.group(2).title()} ({m.group(3)})"


def geocode(address):
    q = urllib.parse.urlencode({"q": f"{address}, Italia", "format": "json", "limit": 1})
    hits = json.loads(get(f"https://nominatim.openstreetmap.org/search?{q}", UA_GEO))
    if not hits:
        # Retry with just "CITY (PROV)" - better a town-centre pin than none.
        city = re.search(r"([A-Za-zÀ-ù' ]+)\s*\((\w{2})\)\s*$", address)
        if city:
            q = urllib.parse.urlencode({"q": f"{city.group(1)}, {city.group(2)}, Italia",
                                        "format": "json", "limit": 1})
            hits = json.loads(get(f"https://nominatim.openstreetmap.org/search?{q}", UA_GEO))
            if hits:
                print(f"  ! only town-level coordinates for: {address}")
    return (float(hits[0]["lat"]), float(hits[0]["lon"])) if hits else None


def main():
    catalog = json.load(open(CATALOG, encoding="utf-8"))
    existing = {c["cinemaId"]: c for c in catalog if c.get("chain") == "twoTickets"}
    ids = set(existing) | set(sys.argv[1:])
    for fid in film_ids():
        ids |= venue_ids_from_film(fid)

    added, updated, skipped = [], [], []
    for vid in sorted(ids, key=int):
        v = venue(vid)
        if v is None:
            skipped.append((vid, "no header"))
            continue
        if not v["has_cinema"] and vid not in existing:
            skipped.append((vid, f"theatre only: {v['name']}"))
            continue
        address = pretty_address(v["address"])
        if vid in existing:
            existing[vid]["name"], existing[vid]["address"] = v["name"], address
            updated.append(vid)
            continue
        coords = geocode(address)
        if coords is None:
            skipped.append((vid, f"NOT GEOCODED, add by hand: {v['name']} - {address}"))
            continue
        entry = {"cinemaId": vid, "name": v["name"], "slug": vid, "address": address,
                 "lat": coords[0], "lng": coords[1], "chain": "twoTickets"}
        catalog.append(entry)
        existing[vid] = entry
        added.append(vid)

    # Same building on two platforms? Flag anything within ~300 m of a
    # cinema from another chain for a manual look - never auto-dropped.
    others = [c for c in catalog if c.get("chain") != "twoTickets"]
    for vid in added:
        e = existing[vid]
        for o in others:
            if abs(o["lat"] - e["lat"]) < 0.003 and abs(o["lng"] - e["lng"]) < 0.004:
                print(f"  ? {e['name']} is next to {o['name']} ({o['chain']}) - same cinema?")

    json.dump(catalog, open(CATALOG, "w", encoding="utf-8"), ensure_ascii=False, indent=2)
    print(f"added {len(added)}, updated {len(updated)}, skipped {len(skipped)}")
    for vid, why in skipped:
        print(f"  - {vid}: {why}")


if __name__ == "__main__":
    main()
```
